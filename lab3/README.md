# Лабораторна робота №3 - OpenCV C++
## Функціонал
* **Фільтри:**
    * `0` - Оригінал
    * `1` - Інверсія
    * `2` - Розмиття
    * `3` - Canny
    * `4` - Sobel
    * `5` - Зум
    * `f` - Розпізнавання обличчя
* **Керування:**
    * `ESC` - Вихід з програми
    * `+` / `-` - Наближення / Віддалення зуму
    * **Миша** - Переміщення зони зуму

---

## Інструкція по запуску

Для зручності всі етапи збірки та запуску автоматизовані за допомогою Bash-скриптів. Ці скрипти знаходяться у папці scripts. 
#### Для коректної роботи програми виконувати скрипти необхідно у такому порядку:

### 1. Підготовка оточення (виконувати 1 раз). Встановлює необхідні бібліотеки (OpenCV, CMake)
```bash
./scripts/preinstall.sh
```
### 2. Компіляція
```bash
./scripts/build.sh
```
### 3. Запуск програми
```bash
./scripts/run.sh
```
